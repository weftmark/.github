# weftmark

**Weaving project management — from design file to finished cloth.**

[weftmark.com](https://weftmark.com) is a web platform for handweavers. Upload WIF drafts from any weaving software, track picks at the loom on a phone or tablet, manage your equipment and yarn inventory, and document your work from warp to finishing.

## Repositories

| Repository | Description |
